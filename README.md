# 🔮 MokTools · 离线工具集

一款基于 uni-app 的离线工具应用，包含周易占卜、小六壬、综合占卜和答案选择器四个模块。业务计算均在设备本地完成。

**本应用仅供娱乐与传统文化学习，请理性看待结果，相信科学。**

默认打开**答案选择器**，可通过底部导航切换模块。首次使用会先显示隐私政策，同意后进入首页。

---

## ✨ 主要功能

### 1. 周易占卜模拟
- 模拟传统三枚硬币起卦（花=3，字=2），随机生成六爻
- 自动计算本卦、变卦，并标注变爻位置（老阴变阳、老阳变阴）
- 显示六爻分数（6/7/8/9）及爻线（阳爻 `===`，阴爻 `= =`）
- 支持填写最多 200 字的问题，复制“温暖”或“真相”模式的解读提示词；应用内未接入 AI 服务
- 结果绑定生成时的问题；修改输入后，旧结果仍复制原问题，重新占卜才会更新绑定
- 两次成功占卜间隔至少 10 秒，支持震动反馈
- **摇一摇暂时停用**：开关隐藏且不启动监听，相关实现保留在 `IChing.vue` 中

### 2. 小六壬
- 随机生成三个 1～12 的整数，依次按大安、留连、速喜、赤口、小吉、空亡推算落点
- 展示三步推算过程与最终落点
- 支持问题输入，复制结果时包含生成结果时的问题

### 3. 综合占卜
- 一次生成小六壬和周易六爻两组结果
- 展示小六壬过程，以及周易本卦、之卦和变爻信息
- 复制综合结果时包含生成结果时的问题、两组结果和解读提示词

### 4. 答案选择器
- 自定义 2/3/4 个选项，输入任意文本，至少填写一个非空选项
- 从非空选项中随机抽取一个，展示约 2 秒的老虎机滚动动画及选中高亮
- 修改选项、切换选项数量或离开页面时取消正在进行的抽取；无法获取滚动项尺寸时直接展示结果
- 震动反馈（视平台支持情况）
- **复制当前时间**：无需先抽取答案，点击时读取设备本地时间，格式如 `现在是2026年10月4日星期日17点44分.`

### 5. 隐私与本地数据
- 业务代码无登录、网络请求或后端服务，也未接入广告、统计和云服务功能
- 输入的问题、选项和生成结果仅保存在组件内存中，未实现记录持久化或云同步
- 隐私政策同意状态通过 `privacy_agreed` 保存到设备本地存储
- 复制功能由用户点击触发，将文本写入设备剪贴板
- 摇一摇已停用；震动反馈依赖设备及平台支持，Android 打包配置仍保留相关权限声明

## 📦 安装与运行

### 环境要求
- 支持 uni-app 项目开发的 HBuilderX
- 当前仓库未提供 `package.json` 或 CLI 构建脚本，使用 HBuilderX 运行和构建

### 步骤

1. **获取项目**
   - 通过 Git 客户端获取实际仓库，或使用已有的本地项目目录

2. **用 HBuilderX 打开项目**
   - 文件 → 导入 → 从本地目录导入 → 选择项目根目录

3. **运行**
   - 运行 → 运行到浏览器 / 运行到手机 App 基座 / 运行到微信小程序

4. **发行（打包）**
   - 发行 → 原生 App-云打包 → 填写证书（Android / iOS）
   - 发行 → 小程序-微信 → 上传至微信公众平台

## 📄 隐私政策

当前业务代码不上传输入内容或结果。隐私政策同意状态保存在设备本地。

隐私政策完整文本可在应用内“隐私政策”链接中查看，也位于 `pages/privacy/privacy.vue`。

首次使用选择“不同意”时：App 端退出应用，微信小程序显示提示，H5 显示提示并停留在隐私页。同意状态只在点击“同意并继续”后写入。

## 📱 平台兼容性

| 功能 | 当前实现与限制 |
| --- | --- |
| 占卜与随机选择 | 本地 JavaScript 计算，不依赖业务服务器 |
| 选择器动画 | 使用组件尺寸查询与 CSS 过渡，需在目标平台确认渲染效果 |
| 复制文本与当前时间 | 使用 `uni.setClipboardData`，受平台剪贴板能力限制 |
| 震动反馈 | 使用 uni-app 震动接口，App 端保留设备震动降级处理，实际效果取决于平台与设备 |
| 摇一摇占卜 | 所有目标平台均暂时停用 |

项目包含 H5、微信小程序和 App 的适配代码；模板编译及静态检查不代表各平台均已完成真机验证。
